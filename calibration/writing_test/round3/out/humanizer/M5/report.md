# Humanizer-zh 改稿报告（M5）

## 按技能执行的步骤
1. 通读 SKILL.md（技能只有这一个说明文件，未要求读其他文件）和 material.md。判断文体为公众号个人随笔：第一人称、口语、有幽默和态度。按“随笔”规则保留作者声音，不加经历和数字。
2. 逐段对照 31 条模式检查，只改确实存在的表达问题。原稿本来比较自然，大部分段落原样保留，因为技能规定“没有问题的段落可以原样保留”。
3. 第一次改完存为 draft1.txt。然后对照原文核对语义，发现初稿有三处改过头，在终稿里撤回了：
   - 把“记账不是让你少花钱，是让你知道钱花哪儿了”改成了“少花钱倒在其次”。这让原文的否定变成了“次要”，弱化了原意，已恢复原句。
   - 去掉了第三条里的破折号，并把“是没有意志力的，只有疲惫”改成“没什么意志力，只剩疲惫”。这削弱了作者的绝对语气，而原破折号起解释作用（模式 8 的保留情形），已恢复。
   - 把“的瞬间”换成“的时候”，属于不必要的改动，已恢复。
4. 通读终稿检查语气和衔接，并做交付前核对：数字（一千二、两年、九天、十几块、三百来块、二十分钟、四个、一个、小两百、一年／一年多）、经历和立场都没变，也没有新增信息。

## 终稿相对原稿的改动（共 5 处小改）
- “真正开始记账是个很偶然的事” 改为 “真正开始记账很偶然”（精简“是个……的事”）
- “记账不是做审计” 改为 “记账又不是做审计”（语气更口语，意思不变）
- “也有人通勤地铁上顺手记。关键是挂在……” 改为 “也有人在通勤的地铁上顺手记。关键是把它挂在……”（补出介词和宾语，读起来更顺）
- “发现视频会员自动续费的有四个” 改为 “发现自动续费的视频会员有四个”（调整语序）
- “一个月省回来小两百” 改为 “一个月就省回来小两百”，“从头到尾没看清过” 改为 “从来没看清过”

## 刻意保留的地方
- 标题和“一、二、三、四”的结构
- 单句段“这个‘下个月’，我整整说了两年”：它带有新信息（两年），不算空洞的戏剧性碎片
- “工具越轻，越容易坚持”“说到底……很多人不是挣得少……”：这是作者自己的判断和立场，技能要求不能以“去痕迹”为由删除
- 结尾的提醒：作者的口吻，而且有具体行动（查自动续费）

## 默认处理说明
用户不在线。技能的默认输出是直接交付改写稿，所以没有提问。作者声音以原稿本身为样本。
原稿有一处小不一致：标题说“记账一年”，正文说“记账一年多”。这属于事实层面，按用户要求没有改动，在这里提醒作者确认。
