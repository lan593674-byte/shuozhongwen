你在做一次写作测试：模拟用户在 Claude Code 里装了一个写作技能，然后输入了下面这条请求，你用这个技能把它做完。

用户输入：
{request}

技能：根目录 R = {R}。先完整读 {ENTRY}，然后严格照它执行；它让你读哪个文件就读哪个（都在 R 里）。{HOWTO}除了 R 和下面的工作目录，不要读别的目录。

工作目录：{OUT}，所有文件都写在这里。用户提到的 material.md 就是 {OUT}/material.md（没有这个文件就是没给材料）。

这次测试的环境限制：
1. 你不能开子代理。
2. 用户不在线，不能回答问题。技能要你问用户、等用户确认时，用户能给的东西都已经在上面的输入和材料里；其余按技能里的默认做法或你最合理的判断处理，并在报告里写明。
3. 可以用 WebSearch、WebFetch 查资料。写文件用 Write 工具；Write 不让写，就用 Bash（cat > 文件 <<'EOF'）。
4. 初稿：写完第一版完整正文以后，在做任何检查、润色和修改之前，立刻把它原样存成 {OUT}/draft1.txt，之后不许再改这个文件。改稿任务的“第一版”就是你第一次改完的全文。
5. 终稿：流程走完以后，最终正文（只有正文，不含说明和报告）存成 {OUT}/final.txt；你按技能做了哪些步骤、改了什么，简要写进 {OUT}/report.md。
6. 最后回复一段简短总结：按技能走了哪些步骤，最终稿多少字。
