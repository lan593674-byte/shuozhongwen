# 修改报告：《最后一班渡轮》

**文体**：短篇小说（文学性文字，按 craft.md 五根柱子写，审读按短篇小说标准）。只给了题目，没有材料，所以没加载 baozhen；事实核查按 --own 标准，存疑项要改到 0。

**主线**：渡轮停航前最后一夜，船工老周的最后一个航次。
**发现**：结束那天跟平常差不多。乘客还是那几个，有人习惯性地说了一声明天见。只有老周抛了二十六年缆绳，一直不用看，偏偏这一次盯着看了，绳子却掉进了江里。人一留意，老习惯就失了手。

**照改的意见**
- 对仗警句「缆绳换过四根，手掌上那层茧一直没换」：改成写实的一句，「最早的那根还是棕绳，后来才换成尼龙的」。
- 前后回扣：删掉老周从排水口抠出橘子、在车上剥开分吃的情节，也删掉老孙那句「江上风大，往常这时候已经困了」。结尾换成新的动作：老孙把车窗摇下一半，冷风灌进来，他也不摇上去。他为什么夜夜坐船，故事里不解释。
- 第 2 轮评委的建议：删掉「过了一会儿」；何师傅骂的那一句改成老周听见的，让视角一直贴着老周。
- 段首短判断句（结构扫描 0.38，没过）：把「到南岸用了十一分钟。」这类句子并进下文，降到 0.23。
