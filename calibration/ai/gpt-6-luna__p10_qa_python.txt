零基础学 Python 做数据分析，可以按“先会用，再做项目”的顺序安排。若每周能投入 6—8 小时，大约用三个月打好基础；进度不必赶，关键是每学一块就动手练。

第一个月学 Python 基础。先掌握变量、数字和字符串、列表与字典、条件判断、循环、函数、文件读写和异常处理。每天学一点，随后用小练习巩固，例如统计一段文本的词频、整理一份购物清单，或读取文件并筛选内容。暂时不用钻研复杂语法，也不必追求背熟，能看懂并改写简单代码更重要。

第二个月开始学数据分析常用工具。先熟悉 Jupyter Notebook，学习用 NumPy 处理数组，用 pandas 读取和整理 CSV、Excel 数据。重点练习查看数据、筛选行列、处理缺失值和重复值、转换数据类型、分组汇总、合并表格。再用 Matplotlib 或 Seaborn 绘制折线图、柱状图和直方图，学会根据问题选合适的图表。每个知识点都找一份小数据练习，别只跟着视频抄代码。

第三个月做完整的小项目。可以分析公开的电影、天气、消费或交通数据，依次完成提出问题、读取数据、清洗数据、计算指标、作图和总结发现。把代码和结论整理成一份 Notebook，写清数据来源、处理步骤，以及分析能说明什么、不能说明什么。项目不必宏大，过程完整、结果可复现就很好。

学习过程中，尽早掌握基础 SQL，练习查询、筛选、分组和连接数据；Excel 也值得保留，实际工作中常与 Python 配合使用。遇到报错时先读错误信息，再缩小问题范围、查文档或搜索关键词，不要直接复制整段答案。每周留出时间复习并重做旧练习。三个月后，根据目标补统计学、可视化表达或更进阶的工具。最重要的是持续练习：学完一个概念，就用真实数据解决一个小问题。
