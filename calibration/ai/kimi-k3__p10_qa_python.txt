# 零基础学 Python 数据分析的学习路线

零基础学 Python 做数据分析，建议按"先语言、再工具、后实战"的顺序推进，整体周期约三到四个月。

**第一阶段：Python 基础（3-4周）。** 重点是变量与数据类型、条件判断、循环、函数、列表和字典、文件读写。不必深究面向对象、装饰器等进阶内容，够用即可。推荐搭配 Jupyter Notebook 边学边敲，每学一个语法点立刻写代码验证，切忌只看视频不动手。

**第二阶段：核心工具库（4-5周）。** 先学 NumPy，理解数组和向量化运算；再重点攻克 Pandas，这是数据分析的核心，要熟练掌握数据读取（CSV、Excel）、筛选、分组聚合、缺失值处理、表连接等操作。学 Pandas 时最好找一份真实数据（如电商订单、电影评分）边学边练。

**第三阶段：数据可视化（1-2周）。** 掌握 Matplotlib 画折线图、柱状图、散点图，再了解 Seaborn 做更美观的统计图表，目标是能把分析结论用图表清晰表达出来。

**第四阶段：项目实战（持续进行）。** 从 Kaggle、和鲸社区等平台找入门数据集，完整走一遍"提出问题—清洗数据—分析—可视化—得出结论"的流程，做 2-3 个项目并整理成作品集。实战中遇到不会的函数再回头查文档，印象最深刻。

两点补充建议：一是尽早学一点 SQL，实际工作中取数离不开它；二是补一些描述统计基础（均值、中位数、分布、相关性），无需很深的数学功底。最后，保持每天 1-2 小时的稳定投入比周末突击更有效。坚持四个月，你就能独立完成常规的数据分析任务了。
