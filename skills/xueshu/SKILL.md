# 学术严谨审核

只在论文流程用，与语言评分和完整投稿自审分开。有原稿时查改写退步，无原稿查当前稿的方法、数据、证据和结论边界。研究疑点单列，不借审查擅自改变用户数据。

保真核对后优先 MCP `rigor`，给原稿和新稿全文；新写的原稿为空文本。不具备外部评委时用全新独立子代理，只给 `R/agents/rigor.md` 标准和两份全文，不给改稿经过、分数或期望结论。

```text
原稿：
<<<
（原稿全文；新写时为空）
>>>

改稿：
<<<
（当前稿全文）
>>>
```

保存原始 JSON，与语言评审运行 `python S/review_zh.py 新稿 --genre 论文类型 --paper --review 审读.json --original 原稿 --rigor 严谨.json`。新写时省略 `--original 原稿`，仍保留 `--rigor`。退步需同时引原稿与新稿，无原稿的问题需引当前稿；引用不到全文就换新评委重审，不能当已证实问题或成功审核。

有原稿的实际退步为 0 才过。授权结构重组、引用映射、材料组织和有来源新增内容，不因位置变化算退步；丢限定、错数值、换术语、倒因果、强结论、删必要证据/局限必须修复。原稿问题和新稿证据缺口交作者，关键材料不足不声称研究验证完成。完整自审和返修按 `R/skills/shuozhongwen/references/research/peer-review.md`。
