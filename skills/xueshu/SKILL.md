# 学术严谨性审查

只在 `/shuozhongwen lunwen` 里用。它回答两个问题：

1. **改稿有没有比原稿更不严谨？** 有一处就不能交稿。
2. **原稿本身有哪些严谨性问题？** 只列给作者，不在正文里改（`baozhen` 约束：数据和论断一个字不动）。

## 怎么审

改稿写完、过了 `baozhen` 的数据核对之后，调用一个全新的子代理做审查。它只看到审查标准、原稿和改稿，看不到改稿经过、评委意见和你的想法。

- Claude Code：子代理类型 `shuozhongwen:rigor`，提示只写：

  ```
  原稿：
  <<<
  （原稿全文）
  >>>

  改稿：
  <<<
  （改稿全文）
  >>>
  ```

  两份都要给全文，不许只摘一部分，不许加说明。
- 其他 agent：开一个全新的子代理，把 `R/agents/rigor.md` 分隔线以下的内容当审查标准，后面接上面那段；或者用 `python S/judge_api.py 改稿 --genre 文体 --paper --original 原稿`，它会用任意兼容 OpenAI 接口的模型同时跑语言审读和严谨性审查。

把返回的 JSON 原样存成文件，和语言评委的结果一起交给 `review_zh.py` 核对（命令见 `references/lunwen.md`）。脚本只认原样引了原文的条目：退步要同时引出原稿句和改稿句，引不出的作废。

## 结果怎么用

- **退步（regressions）**：每一条都要处理，办法只有一个，把改稿那句改回原稿的意思和强度（可以换一种不带 AI 腔的说法，但数据、限定词、因果、术语跟原稿一致）。改完换一个全新的审查子代理重审，直到退步为 0。
- **原稿问题（issues）**：一律不改正文，原样写进修改报告的“学术严谨性审查（待作者处理）”，每条写：原句、问题类型、问题是什么、作者可以怎么处理。子代理说“存疑”的外部数据，你能查到来源就附上来源，查不到就写“未能核实”，不要替作者下结论。

## 你自己也要守的几条

改论文语言时，下面这些改动看着像“润色”，其实都是严谨性退步，不要做：

- 把“可能”“初步”“在本数据集上”删掉，或者把“主要”写成“都”
- 把“表明”“说明”换成“证明”，把相关写成“导致”
- 把没做显著性检验的“差异较大”写成“显著”，或者反过来把原稿的“显著”（有检验支撑时）弱化成“明显”
- 给结果加原稿没有的解读（“意味着……”“说明模型已经可以用于……”）
- 把术语、模型名、缩写换成近义词，或者统一成你以为对的写法
- 为了读着顺，合并两句话时丢掉其中一句的前提或局限
