# 说中文 · 清理

插件根目录 `R` = `${CLAUDE_SKILL_DIR}/../..`，脚本在 `R/scripts`（下称 `S`）。Python 用 `python3 -X utf8`（Windows 上是 `python -X utf8`），需要 3.10 以上。没有 Python 时，告诉用户需要装 Python（Windows：`winget install Python.Python.3.12`），不要自己手工删字符代替。

## 清什么

- 零宽字符和其他不可见字符：U+200B、U+200C、U+200D、U+2060、正文里的 U+FEFF、双向控制符、标签字符等
- 乱码：U+FFFD 替换符、控制字符、“锟斤拷”“烫烫烫”，以及编码读错造成的错乱（“涓枃”→“中文”、“Ã©”→“é”）

不动的：空格、换行（CRLF 保持 CRLF）、文件编码、文档格式和元数据。文档（.docx .pptx .xlsx .odt .epub 等）只改文字内容。图片、PDF、音视频不是文字，跳过；要清它们的来源元数据，用 `python S/clean_file.py 文件 -o 输出`。

## 怎么做

1. 认清目标：
   - 用户给了文件或文件夹路径：直接用。
   - 用户贴了一段文字：把它原样写进一个临时文件（不要先自己改），再对这个文件跑；清完把清理后的文字给用户。
   - 用户说“上一条回复”“这段话”这类：取那段文字，同上。
   - 没说清楚：问一句要清哪个文件或哪段文字。
2. 先只检查，看看有什么：

   ```
   python S/qingli.py 路径 [更多路径] --check
   ```

3. 再清理（原地修改，改之前自动备份原文件，备份位置会打印出来）：

   ```
   python S/qingli.py 路径 [更多路径]
   ```

   用户明确说不要备份才加 `--no-backup`。只要报告、不想改文件时，停在第 2 步。
4. 向用户报告，按脚本输出整理，不要省略：
   - 每个文件清除了什么、各多少个，位置（第几行、前后文字；看不见的字符在报告里写成 ⟨U+200B⟩ 这样）
   - 修复了哪些编码错乱：原来的样子 → 修复后的样子；标了“字节已丢失”的，说明修复后可能仍缺字
   - U+FFFD 和“锟斤拷”所在的位置：原来的字已经丢了，清除只是去掉了占位符，那里需要作者补回原文
   - 跳过的文件和原因，仍未解决的问题
   - 原文件备份在哪里，怎么还原（把备份复制回原位置）

不要在报告之外顺手改文件的其他内容。
