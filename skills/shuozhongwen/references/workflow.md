# 改稿工作流：事实账本、回读、修改报告

SKILL.md 的流程管整体顺序（备料、提纲、初稿、自查、审读、按证据改、交稿）；改稿时，下面几段是细则：动刀前锁事实、按症状扫描、怎么下刀、改完分三遍回读、交稿时的修改报告。这里的判据大多从好好说话（haohao-shuohua）原样搬来。

---

## 改稿五段流程

### 起手：认文体，定主线

动手前先认文体（SKILL.md 第 1 步）：实用、议论还是文学性文字。文学性文字先读 `craft.md`，回答两个问题再往下走：这篇最值得写的“发现”是什么？用哪根主线把材料串起来？答不上来，先别改句子，改句子救不了没有主线的文章。

**事实与细节的边界**：改稿和根据材料新写（按 `baozhen` 约束），原稿或材料没有的细节、经历、引语、数字一律不补，缺了就在修改报告里列出“建议作者补充的细节”；只给题目、没有材料的文章，可以补查得到的真实细节，写之前心里核对一遍，拿不准的不写。

### 第一段：事实闸门(改前锁账本)

改任何一个字之前，先把**关系账本**列出来。账本 8 项：

- **数字**：所有数字、单位、比例、时间、人名。
- **命令 / 代码 / 术语 / 专有名词**：凡是引号、代码块、`code` 包住的、以及首字母大写的英文术语，视为不可修改的**受保护跨度**(protected span，详见 `protected-spans.md`)。
- **谓词方向**：「A 导致 B」不能变成「B 导致 A」;「A 大于 B」不能变成「A 小于 B」;「A 属于 B」不能变成「B 属于 A」。
- **效果类型**：上升 / 下降 / 不变 / 存在 / 消失，不许翻转。
- **关系类型**：因果 / 并列 / 转折 / 递进 / 让步，不许换。
- **模态**：「可能」「一定」「大概率」不许升级或降级。
- **硬机制描述**：「Q-K 点积加权求和」「反向传播」「AST 遍历」这类精确算法/机制描述，不许替换成比喻或简化说法。想加比喻，叠在机制后面(先给准确机制，再补比喻)，不许替换。
- **论文级证据**：「Kenneth Li 等在 Othello-GPT 里发现……(ICLR 2023)」这类可追溯的实验描述，作者/机构/年份/结论不许被简化成「有研究发现」「科学家表示」。

账本用几行清单记住(或写到暂存区)。改完最后一步逐条对回去。**任何一条对不上，该句作废，回去重改**。

### 第二段：症状库五层扫描 + 回译兜底

按 `symptom-dictionary.md` 逐层扫描，标注命中项：标点级 / 句式级 / 词汇级 / 结构级 / 结构排比级。

标注完密度先自检：**某段命中 > 5 处 → 该段整体不对，单点改不救，直接整段重写；用户说了「别大改」，就把整段列进删除清单**。

**回译测试兜底**：任何一句拿不准是不是 AI 味，默读一遍翻回英文。英文一次成型 → AI 味；英文别扭需要意译 → 中文。**注意**：回译是给人用的疑难句判定器，不逐句逐段跑，不当自动化流程的门槛(极简白话/技术议论中文本身回译也顺，别一刀切)。

**回译也管单个可疑词(借译词)**：碰到一个词读着别扭、又说不上哪儿不对，把这个词单独翻回英文。**一翻正好是个地道英文词、而中文另有更顺的现成说法 → 就是照着英文硬拼的借译词，换掉。** 典型 Bad Case:「死线」→ deadline，中文本来说「截止时间 / 最后期限 / 交稿日」。**边界(重要，防误伤)**：只测那些**读着就别扭、圈子外听不懂**的词。已经进日常、或计算机领域本来就这么叫的标准词——软件、硬件、进程、线程、指针、句柄——不测不动，它们没有更自然的替代。判据只有一条：**有没有一个更顺的现成中文能替？有才换，没有就留。**

### 第三段：按"改多狠 × 动多大范围"动刀

按上一段扫出来的密度和用户要的改法（改多狠、动多大范围，见 `rules.md`「改多狠」）下刀：

- **减法下刀**(见 `symptom-dictionary.md`「下刀」节)：名词化→动词；后缀病→删或换；破折号→逗号/句号；前者后者→重复主语；长复合句→短句串珠。
- **加法自问**(见 `rules.md`「加中文味」几问 / `chinese-four-principles.md`)：动词扛住了没？有具体没？句子该补气口/拆开没？段末多话删了没？

**范围限在句段内时的硬约束**：
- 不擅自删整句。发现某句该删，记进**「建议删除清单」**，主流程末尾统一交作者定夺。
- 结构级重排(合并两段、拆分一段、调整章节顺序)必须先问，不许直接做。

**范围放开到可动结构时**：结构级重排可自主做，但每次都要在修改报告里说明「原来是……，改后是……，因为……」。

### 第四段：回读

改完不许直接交。分遍念，**三遍分开做，不许合并**(合并的结果就是「越改越顺、越顺越不像原稿」，最终跑题)：

- **第一遍 · 只对事实**：拿第一段的关系账本一条条对回去。**只查、不改结构、不查行文**。任何一条对不上，回第三段重改该处。
- **第二遍 · 只查残留 AI 味**：整篇再念一遍，只找漏网的五层症状。**发现问题只做局部替换，不许借机重写全文**，这步是收尾，不是再来一遍。**这一遍也把四条机械扫描再跑一次**（`quick-scan-regex.md`），看有没有改稿过程里新长出来的、或者第一遍漏掉的。手和眼是同一双，机器扫是这一层唯一的第二只眼。这一步跑本插件的 `polish_check.py 稿件`：同一套正则，外加不可见字符和 AI 相似度。AI 相似度落在 high，才按它列的待改项改，改法是补细节、删套话、调节奏，不是重复用词、硬塞标点；不在 high 就算过，不再往下压。仍然只做局部替换，不借机重写；改了会违反保真或红线的项不改，写进修改报告。
- **第三遍 · 节奏终审**：按 `rhythm-check.md` 四个字面指标(憋气句/句长单调/软尾串/调子单一)粗筛标红，逐处念一遍定夺。**只补气口、只微调句式，不推向口语化，不拆好长句。** 误报(URL、排比、专名列表)放过。

**收尾一问(减法都查完再问一遍)**：这稿子除了「没病」，有没有一句是作者自己想说的、砸得下去的实话？一句都挑不出来 → 它还是白水汤，回 `craft.md` 补细节、补发现。

**编辑审读(对外成稿必做)**：自己问完，再请评委：按 SKILL.md 第 5 步，调用全新的 `shuozhongwen:judge` 子代理，只给它文体和正文，不给改稿经过、上一轮评语或作者信息；再用 `review_zh.py` 核对它引的证据是不是原文原句（引不出原文的分数作废）并判通过。**用的是它的证据和改法，不是它的分数**：分数只是过线的门槛。没过线，就照最弱项的改法改，改完换一个全新的评委再审；过了就停，不为把分数往上刷再改（分数是伪精确，追分会把文章改成讨好评审的样子）。评委提出的改法要过保真这一关：让你“补一个具体细节”，改别人的稿子时不能编，只能列进“建议作者补充”。

### 第五段：主线反思(软性，不强制约束)

改完自己回读全文，回答三问，跟着修改报告一起给：

1. **主线是什么？** 一句话讲清整篇核心主张。讲不出来 → 主线已散，需作者定夺是否重来。
2. **每一节还在为它服务吗？** 逐节问「删掉这节，主线还立得住吗？立得住 → 这节是废段，标出来。」
3. **比改之前更清楚，还是更散？** 只跟改前比，不跟理想比。改后更散(常见于补丁摞补丁)→ 标出偏离点交作者，**不擅自回滚**。

**不当硬约束**：有时候作者就是想改结构、想让主线松一些，不能限死。这步只做提醒。

## 修改报告模板

```
<正文>

【修改报告】

【文体与任务】
- 文体：……；任务：……（第 2 步复述的那句）；主线：……

【数据核对】（改稿和根据材料新写时必给，按 baozhen 约束）
- 数据清单 N 条（数字、表格、引用、术语、限定词……），逐条对过，全部一致 ✓
（对不上的已改回原稿写法）

【待作者核对】（原稿里看起来有误、但按约束没有改的数据和事实）
- 原稿「……」：疑点……；查到的来源……（查不到就写“未能核实”）

【本次动刀】
- 下刀命中：XX 处（简要 1 行）
- 加法补充：XX 处（简要 1 行）

【编辑审读】（对外成稿必给；填 review_zh.py 核对后的结果）
- 审读轮数：……；六项：具体 N / 发现 N / 语言 N / 节奏 N / 结构 N / 声音 N；白开水：是/否
- 照改的意见：……（哪条意见，改了哪里）
- 没照改的意见及理由：……（比如要补的细节原文没有，已列进“建议作者补充”）

【精修】（文学性文字必给，SKILL.md 第 7 步）
- 改了什么：……；polish_check：通过 / 未通过
- 对比评委：原稿在 A 时判 ……，新稿在 A 时判 ……；交的是：新稿 / 原稿（理由）

【建议作者补充的细节】（改稿和根据材料新写时给）
- ……

【机械扫描与 AI 相似度】（对外成稿必给；填 polish_check.py 的结果）
- 半角标点 N / 章节编号 N / 元话语 N / B2 N；结构套路：通过 / 未通过（哪几项）；AI 相似度 0.xx（低/中/高）
- 结论：通过 / 未通过（未改的项及理由）

【建议删除清单】（用户说了「别大改」时给）
- 第 N 段第 M 句「……」建议删，理由：段末打钉/同义反复/凑三/……

【主线反思】
- 主线一句话：……
- 有无偏离：无 / 有（说明哪一节偏了）
- 比改前：更清楚 / 更散（简答）
```
