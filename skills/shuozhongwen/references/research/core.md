# 核心写作规范

用于论文新写、改写、润色和翻译的正文判断。来源为 research-writing-skill 的 writing-core 及其兼容模块；任务规划见 [planning.md](planning.md)，保留数据与事实仍须执行上层保真流程。

## 自然表达与信息保留

去 AI 化处理模板腔、翻译腔、过度概括和空泛拔高，不等于压缩内容。没有明确缩写要求时，不主动删减研究对象、数据范围、样本口径、方法条件、指标含义、解释句、实验边界和结论限制。原文已清楚自然，只改实际问题；必要的承接、限定和少量重复应保留。

| 症状 | 判断与处理 |
|---|---|
| 连续使用首先、其次、最后、此外、另外、接下来、总之 | 用实际因果、转折、递进或对象变化连接；不要逐项换成另一套连接词 |
| 值得注意的是、需要指出的是、重要的是、必须强调的是、显而易见 | 删除空壳引导，直接说要说明的事实；必要限定写入事实本身 |
| 非常、极其、十分、相当、关键、显著、具有重要意义却无依据 | 写具体指标、现象和条件；没有证据时收束判断 |
| 我认为、我觉得、我个人看法是、我的研究 | 正文用本文、本研究、研究对象或结果作为主语；学科允许的论证立场见学科参考 |
| 句式像英文直译 | 调整中文语序，先交代对象、资料范围或现象，再说明处理方法和判断 |
| 每段固定背景—方法—结果—意义，每句固定对象—动作—结论 | 按真实论证关系组织，保留解释句与承接句，避免换一种机械模板 |
| 该指标反映的是、不能理解为、用于避免口径悬空等审稿回复口吻 | 改为正文叙述，例如本文将某指标作为某种参照；限制本身不能删 |
| 改短后含义变少 | 补回对象、时间、样本、条件、评价对象和限制，再处理语序 |

当用户反馈“太 AI”“太精简”“像翻译”，按信息是否丢失、中文语序、段落是否套模板、是否是审稿回复口吻、判断是否过强依次检查，不能只继续删词。

## 句子与段落

- 一个句子围绕一个主要关系展开，保留必要条件、范围和解释。长短句交替，但不人为追求句长差异。
- 优先清晰的主谓关系、具体动词和可验证信息；避免名词化导致的空转。英文可用主动语态，但研究对象更重要或学科惯例要求时保留被动语态。
- 列表转段落前重建逻辑链，补足主语、谓语、连接成分和指代对象，不能把条目句生硬拼接。
- 一个段落集中说明一个核心问题，通常有主题、支撑、解释或收束；不要求每段都按相同顺序。
- 中文正文 150—300 字、英文 100—200 词可作段落检查参考。完整观点不为凑长度拆成许多短段，也不为达到范围塞入废话。
- 可使用“本文”“实验结果表明”“表 X 显示”等客观主语，但不能连续重复同一模板。有真实结果才可使用结果性表述。

## 排版

正文默认连续段落，段落间空一行，不用加粗、斜体或引号作装饰强调。标题层级清楚。引号作为直接引文、术语约定或作品名称的一部分时按学科规范保留。

计划、检查清单、参数配置和操作步骤可以用列表。论文正文不以项目符号堆叠观点；目标体例允许贡献列表时，最多保留三个真正独立的贡献，并由前后段落解释。正式模板要求的摘要标签、术语首次定义和表格标注按模板处理。

中文正文使用中文全角标点，保持数字、单位、英文术语、括号和空格一致。公式、代码、引用标记、专名及原始数据的保护优先于形式统一。

## 事实与引用

不编造文献、数据、方法、实验现象或经历。结论性表述应能指向来源或数据；引用存在不等于引用支持当前结论。全文固定一种目标体例，例如 GB/T、APA、IEEE、MLA 或法学脚注，按目标学校或期刊要求确定版本。证据级别与支持范围见 [evidence.md](evidence.md)。

## 三轮自查

结构轮：检查论证连续、单段中心、正文列表化、机械模板段、章节重复与遗漏。

语言轮：检查模板过渡、空壳强调、无信息修饰、主观判断、翻译语序、审稿回复口吻，以及压缩造成的数据口径或结论边界损失。确认“提升”“稳定”“有效”能由具体数据或现象支撑。

排版轮：检查不必要强调、段间空行、标点、中英文空格、标题和引用体例。

自查通过只表示已检查的写作问题得到处理，不构成 AI 检测结果，也不能证明文本由谁写作。查 AI 率仍使用原有检测流程，报告真实工具结果或明确标示尚未检测。
