# 统计结果的选择、描述与核对

整合 statistical-analysis 技能及模块的写作相关部分。用于理解用户已有分析、规划报告字段与撰写结果，不自动安装分析环境或用示例数据替换研究数据。计算或检验仅在任务实际需要、数据可用且工具已可用时执行，报告实际证据。

## 选择检验的写作检查

| 设计与数据 | 候选方法 |
|---|---|
| 两组独立连续数据，适合参数模型 | 独立样本 t；方差不等时考虑 Welch t |
| 两组独立连续/有序数据，分布或目标不适合参数模型 | Mann–Whitney U；说明其检验目标，不自动等同均值比较 |
| 两组配对连续数据 | 配对 t；检查差值分布，或按条件用 Wilcoxon 符号秩 |
| 分类/二分类计数 | χ² 或 Fisher 精确检验，按独立性与计数条件 |
| 三组及以上独立连续数据 | ANOVA；条件不适用时考虑 Welch/Brown–Forsythe 或 Kruskal–Wallis |
| 多时点/条件配对数据 | 重复测量 ANOVA 或 Friedman；说明重复设计和适用条件 |
| 连续变量关系 | Pearson 或 Spearman，依关系形式、分布和异常值判断 |
| 连续结果与预测变量 | 线性回归，报告模型、诊断与假设 |
| 二分类结果与预测变量 | 逻辑回归，报告 OR 与区间及控制变量 |

上表是分析/报告核对起点，不靠“正态/非正态”一项机械决定方法。确认独立/配对、研究单位、变量尺度、样本、离群值和预设问题。参数假设通常针对差值/残差或相应模型，而非所有原始变量。

## 假设与缺失数据

解释前检查并报告独立性、适用正态性、方差齐性及模型特定条件。Shapiro–Wilk、Levene 等诊断的非显著结果表示未发现足够违反证据，不是证明分布或方差假设成立。结合设计、分布/残差诊断、样本和稳健性说明，不把 n>30 当普遍免检规则。

不等方差时可报告 Welch，回归可依实际采用稳健标准误或加权模型；改变分析必须有理由并记录，而非为得到显著结果。缺失数据写数量、模式、实际处理和限制；涉及 MCAR、MAR、MNAR 时说明假设依据，不能无材料断言机制。

## 效应量、置信区间与功效

p 值不是假设为真的概率，也不直接证明效应存在或有实际意义。报告适用效应量与置信区间：t 比较可用 Cohen's d，方差分析可用 η²/偏 η²，相关用 r，回归给系数与 R²，计数可用 Cramér's V。区分不同效应量定义，不能互换。

上游小/中/大效应示例（d 0.20/0.50/0.80、r 0.10/0.30/0.50 等）只能作为领域讨论参考，不能脱离研究情境给结果定性。置信区间要说明对象与计算依据。

样本量计算来自事前设定的效应、显著性水平、功效、组数/组比与设计；不得反向伪造事前计划。研究后敏感性分析可说明当前样本能检测何种效应，不用观察到的 p 值再计算“事后功效”证明结论可靠。

## 最小报告字段

- 研究问题/假设，预设或探索性状态。
- 每组/变量样本量、适用均值和 SD 或其他真实描述统计。
- 检验名称、统计量、自由度、精确 p 值或极小值阈值、单双侧。
- 效应量和区间、方向、单位与实际含义。
- 假设诊断及违反后的处理，缺失/异常值规则。
- 事后比较及多重校正、全部计划分析，包括非显著发现。
- 实际软件、版本、数据与分析输出位置。

## APA 类报告模板

模板仅填已有分析结果，不能补造统计量、样本或区间。体例按目标要求调整。

```text
两组比较：A 组（n=[nA]，M=[MA]，SD=[SDA]）与 B 组（n=[nB]，M=[MB]，SD=[SDB]）
在 [指标与单位] 上的 [实际差异] 为 [值/区间]；[检验名称]，t([df])=[t]，p=[p]，
[效应量类型]=[值]，95% CI [下限，上限]，[单/双侧]。适用诊断及处理为 [实际情况]。

方差分析：条件对 [结果] 的 [实际发现]，F([df1], [df2])=[F]，p=[p]，
[η²/偏 η²]=[值]。采用 [实际校正/事后方法] 的比较显示 [所有计划比较和区间]。

回归：以 [变量] 预测 [结果]，模型 [实际整体统计量]，R²=[值]，调整后 R²=[值]。
[预测变量] 的 B=[值]、SE=[值]、β=[值（如适用）]、p=[值]、95% CI=[区间]。
控制变量、共线性/残差诊断及未显著变量为 [实际结果]。
```

## 不可越过的解释边界

禁止 P-hacking、结果切换、挑选结果、把探索发现写成预设验证、忽略混杂或缺失。多重比较按实际家族和分析计划适当校正，不能为“好看”删去未显著比较。相关不等于因果；无统计显著不等于证明无效应。只有确实完成等效性/非劣效性等设计时，才报告相应结论。

核对每个数字与输出；SD/SE/CI 不混写，OR/HR/RR 不混写，原始 p 值与校正 p 值不混写。若只有描述数据，撰写描述性比较并明确范围，不生成虚构检验结果。
