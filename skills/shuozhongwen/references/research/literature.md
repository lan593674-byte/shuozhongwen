# 文献检索、整理与综述

整合 literature-review 技能和兼容模块。只使用当前环境已有检索、浏览、PDF 提取或用户材料，不要求安装上游脚本和新增依赖；证据到正文的强制关系见 [evidence.md](evidence.md)。

## 检索前确定范围

提取主题、研究问题、学科、时间范围、语言和纳排条件。生成中英文主题词、同义词和领域术语，先宽检索认识方法脉络，再聚焦具体问题。布尔组合 AND/OR/NOT、引号精确匹配、年份和文献类型过滤应按数据库支持使用，不默认为所有站点语法相同。

优先用户已有文献池；英文可检索后验证，中文优先用户可访问的知网、万方、维普资料与可靠公开来源。数据库需要登录、订阅或无法检索时给具体检索式和纳排建议，继续处理已有材料；不能声称所有中文文献一律无法检索，也不能绕过访问限制。

| 来源 | 使用条件与定位 |
|---|---|
| Crossref/DOI/出版商页 | 核对题名、作者、年份、刊物和 DOI；元数据不等于全文证据 |
| PubMed | 生物医学检索与摘要；核对文章类型和实际可见资料 |
| arXiv | CS、物理、数学预印本；明确预印本状态，不冒充正式发表版本 |
| Semantic Scholar/Google Scholar | 发现相关研究、引文追踪；关键事实回到原始来源 |
| IEEE Xplore/期刊或会议官网 | 技术研究的原始出处和目标要求 |
| CNKI/万方/维普/用户机构数据库 | 中文文献，按实际访问能力检索或接收用户导出 |

近五年文献常用于定位近期进展，经典理论与基础方法保留原始来源；不以时效或被引量代替相关性与严谨性。

## 检索日志与去重

持续项目在 `plan/notes.md` 记录数据库、日期、查询式、时间过滤、返回数量、筛选原因与不可访问项。去重结合 DOI、规范题名、作者和年份，识别预印本与正式版关系，避免同一研究重复当独立证据。

系统综述明确纳排标准、筛选步骤、全文获取情况和每阶段真实计数，供报告规范使用；不补造筛选人数、排除理由或 PRISMA 流程数量。

## 文献记录与质量判断

```markdown
## Source [ID]
- 标题、作者、年份：
- 期刊/会议/出版社、文献类型：
- DOI、原始链接、访问日期：
- 阅读范围：全文/摘要/用户摘录/元数据
- 核心观点、研究方法、主要结论及条件：
- 与本研究关系、可引用事实：
- 贡献、局限、反例或不确定项：
- 支持的具体论点与 citation slot：
```

质量判断包含相关性、出处与来源可靠性、时效性、方法严谨性及实际参考价值。引用次数、作者影响力、刊物分区只是背景线索，不证明结论正确。形成按主题、方法、对象、条件、贡献和限制组织的 literature matrix，再建立证据映射。

```markdown
| Source ID | 主题/方法家族 | 研究对象和条件 | 主要可见发现 | 贡献 | 局限 | 与本文的支持/补充/矛盾关系 |
|---|---|---|---|---|---|---|
```

## 综述组织与写作

综述通常说明背景和范围，再按主题或方法比较现状，随后评述贡献、限制和趋势，落到研究空白与本文切入点。历史、思想或学派演变可以用时间脉络，但仍须有比较和解释。

“张三研究 A，李四研究 B”只完成笔记复述。综合段应指出两项研究面对的同一问题、采用不同路线的原因、结果的可比范围、相互支持或矛盾及尚未覆盖的条件。对“取得显著进展”“仍缺系统研究”等判断需要可读到的证据，不能靠模板自动生成。

可执行句段蓝图：

```text
主题：界定这一研究路线解决的共同问题。
证据：比较来源 A/B 在对象、条件、方法与发现上的联系。
评述：指出共同限制或结论差异，不超出阅读层级。
承接：说明本文为何处理其中一个具体问题。
```

至少形成 evidence-claim map 后才可称综述综合完成；引用数量和搜索结果列表不构成完成证据。

## 引用体例与管理

目标要求优先，全文统一。可接收已有 Zotero、EndNote、Mendeley、NoteExpress 或 BibTeX/RIS 导出，不主动安装管理工具。常见写法示例中的字段必须回填真实元数据：

```text
GB/T： [序号] 作者. 题名[J]. 刊名, 年份, 卷(期): 页码.
APA： Author, A. A. (Year). Title. Journal, Volume(Issue), pages. DOI/URL
IEEE： [序号] A. Author, "Title," Journal, vol. V, no. N, pp. P1–P2, Year.
```

期刊、图书、会议、古籍、法条、病例或预印本采用对应类型；不要强行要求所有来源都有 DOI。缺页码、卷期、作者或年份须核实或明确缺项，不猜填。

## 核验

- 用 DOI 解析、原始出版商、数据库记录或可靠原文核对文献身份；解析成功之后还须核对信息一致。
- 核对作者、年份、标题、出版版本和全文所引内容，不只验证链接存在。
- 正文引用与参考文献列表双向对应，引用位置有清楚支持关系。
- BibTeX/RIS 的解析、键值和字段一致性按已有工具检查；重新检索输出一个文件不等于验证原文件。
- PDF 用现有提取工具读实际内容，检查扫描件、乱码、表格/公式误识别和缺页。自动摘要回到原文核对；报告实际读到哪些段落，无法提取的部分不推断。

文献不足时扩展同义词、放宽合理时间范围、检索综述参考文献、进行引用/被引追踪或研究相邻领域。文献过多时以直接相关和方法可靠为先筛选，再考虑代表性与近期进展；不能只按高被引或刊物等级排序。
