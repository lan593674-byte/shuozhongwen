# 人文与社会科学写作

整合 writing-humanities 技能及模块增量。共用 [core.md](core.md)，涉及文献综合时使用 [evidence.md](evidence.md)，量化社科结果使用 [statistics.md](statistics.md)。

## 类型与论证结构

人文学术正文以论证、理论和材料解释为核心，结构比实验论文灵活；可使用经典文献，不因年代久就淘汰。文学评论用文本细读与理论，历史研究用史料与来源批判，哲学用概念辨析和推理，教育/社会研究按实际设计结合理论、访谈、案例或调查。

| 结构 | 适用逻辑 |
|---|---|
| 总—分—总 | 核心论点 → 分论点与证据 → 回应总体问题 |
| 递进 | 现象 → 原因 → 深层解释 → 理论建构或方案 |
| 对比 | A/B 观点 → 同一标准比较 → 综合评价与立场 |
| 问题导向 | 问题 → 文献 → 理论框架 → 分析 → 回答 |

论点必须明确、具体、可论证；“作品很伟大”不能代替可检验的文本判断。论据可以是原文、史料、理论观点、案例、统计；每项论据都解释如何支撑论点，不能以引用代替自己的分析。概念范围和推理步骤须清楚，回应可能的反驳和相反材料。

## 学术语体与自然衔接

准确使用学科术语，说明理论视角与材料范围；表达可有适度文采，但不能以情绪形容词替代论证。默认本文或客观对象叙述；学科惯例允许“本文认为”“笔者主张”时保留论证立场，不将其误判为口语“我觉得”。

“学界普遍认为”“众所周知”需要可证实的范围和来源，不能作为替换口语的自动捷径。“可以推断”“具有一定合理性”“存在值得商榷之处”必须交代理由，不是给绝对判断套一个谨慎词。

用“在某语境下”“从某理论角度”等明确分析条件；“体现”“反映”“揭示”后必须说明具体文本或材料关系。段间过渡回扣主论点，不靠固定过渡词。

## 引用、古籍与译著

直接引用短句可融入正文并加引号，长引文按目标体例另起缩进段；长度界限由体例决定，不把上游“40 字”示例当通用标准。转述也标注来源，综合引用明确不同观点的关系。

著作记录作者、题名、出版地/出版社、版本、年份和页码；古籍标作者时代、版本、卷次/页码；译著记录原作者、译者、版本与定位。例句仅表示格式，不授权写入未经核实的书目信息。

引用的目的是支持论点、提供背景、与已有观点对话或批判分析。每项重要引用有分析评论，不堆砌引文。是否引用过多根据实际体例和分析比例判断，不把“全文 20%”作为普遍硬阈值或与查重率混淆。

## 各章检查

引言由宏观到具体，说明问题、现状、独特视角、方法和范围；全文 10%—15% 可作规划参考。综述按主题、时间、学派或方法组织，必须评述贡献与空白。

正文每章交代本章问题，分节分析，必要时小结；保持论据与主张联系、章节之间的逻辑递进，避免重复或脱离主题。结论总结实际发现、理论/实践含义和局限，不加新论据，不做脱离材料的拔高。

## 常见失败与修订

- 论证薄弱：论点与论据脱节、推理跳跃、引用代替分析。补充证据到主张的理由，而非单纯增加引用量。
- 结构松散：章节无关系、偏离主题、重复论述。回到大纲确定各章作用，调整重复，不能删掉关键反例。
- 语言问题：口语、术语不准确、长句难懂。先明确概念和句间关系，再调整句式；保留必要限定。

验收核对论点可论证、证据充分可靠、反驳得到回应、章际关联、引用与参考文献对应、引用有评论、专业术语一致和语言准确。
