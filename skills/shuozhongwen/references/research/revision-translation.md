# 改写、翻译、润色与篇幅调整

整合 prompts-collection 技能与兼容模块的所有写作模式。原始评审打分、保真校验和 AI 率检查由 shuozhongwen 既有流程执行；本文件指导如何根据评审意见改稿，不能用写作自评替代检测。

## 先确定具体模式

读取用途、读者、语种、格式、目标篇幅、原文和保留项。原文清楚就保留，不为体现改动而改。学术正文采用 [core.md](core.md)；期刊/学校的明确体例及用户指令优先。保护数字、单位、事实、限定、专名、公式、代码、引用命令和交叉引用。

## 中文到英文学术翻译

```text
任务：将中文草稿翻译并润色为英文学术正文。
判断：保持技术含义、数据口径和论证关系；用常见准确词，清晰主谓关系；必要时调整英语句法。
约束：不用装饰加粗/斜体/引号，不用 item 列表堆砌；保留合法术语与引用；不扩充不存在的事实。
输出：Part 1 [LaTeX 或目标格式]；Part 2 [对应中文直译]。
```

目标不是 LaTeX 时不强制转为代码。中文直译用来核对英文含义，不擅自改成另一个更强的中文论点。

## 英文到中文：理解与正式翻译分开

快速理解模式严格直译，不主动润色，只输出可读中文段落；仅在用户需要“纯文本理解”时移除 `\cite{}`、`\ref{}` 等排版命令。正式翻译保留引用、交叉引用和公式，并维持可追溯性；不能将快速理解的删命令规则用于最终论文。

专名与技术术语遵循原文及学科用法，必要时首次给中英对应，不强行翻译 Transformer、CNN、Few-shot 等明确术语。

## 英文润色与去 AI 化

英文润色修正语法、逻辑与句式，采用准确正式书面语，按体例处理缩写形式，保留 LaTeX 命令与数学表达。

去 AI 化检查高频装饰词、机械衔接、列表化和空转开头；item 内容先还原论证关系再写为连续段落。原文自然则保留，不能为换词牺牲专业含义。

| 容易成为装饰的词 | 依语境可用的平实表达 |
|---|---|
| leverage | use, employ |
| delve into | investigate, examine |
| tapestry | context, framework |
| underscore | highlight, show |
| pivotal | important, key |
| nuanced | detailed, subtle |
| foster | encourage, support |
| elucidate | explain, clarify |
| intricate | complex, detailed |
| paramount | important, critical |

词表是检查线索，不是术语黑名单；本来准确的专业用法不机械替换。去除 First and foremost、last but not least、it is worth noting that 等无信息衔接，保留实际关系。

```text
输出：Part 1 [LaTeX/英文正文]；Part 2 [对应中文直译]；Part 3 [Modification Log]。
无需实质修改时在修改说明标记 [检测通过]，仅表示本轮语言检查。
```

## 中文轻润色

只处理口语、语法、逻辑断层、指代或实际术语问题，原文已清晰保留。采用中文全角标点，Word 使用场景输出纯正文，不加 Markdown 强调、标题和编号装饰。

```text
Part 1 [Refined Text]：润色后的中文段落。
Part 2 [Review Comments]：实际问题与改动理由；没有问题则说明已保留。
```

## 中文期刊论文去 AI 化：信息保留模式

先锁对象、数据、样本、方法条件、指标、实验边界、结论限制及专名，然后处理模板过渡、空壳强调、翻译语序、审稿回复口吻和空泛判断。去 AI 化不主动缩减，没有明确缩写需求就保留解释句。

正文连续段落，减少不必要拆分，不能生硬拼接条目。保留自然的稍长句、必要承接和少量重复；不把所有句子压成“对象—动作—结论”。效果与意义优先据指标或现象表述，缺证据时收束判断。

```text
Part 1 [Refined Text]：可直接用于论文的中文正文。
Part 2 [Modification Log]：改了哪些问题，是否处理翻译腔、模板腔、审稿回复口吻或空泛判断。
Part 3 [Information Check]：对象、数据、方法、指标与边界的保留情况；存在风险时明确指出。
```

目标读者模式：先确定本领域审稿人或跨学科读者，再决定术语解释与细节粒度；首次解释陌生术语，用具体动词，减少名词化、“it is/there is”或“有必要指出”等空转开头。不能以读者变化删除必要方法和条件。质量说明可控制在三句以内。

原文含真实实践观察或作者视角时，可保留与论点直接相关的观察；不添加虚构经历，也不扩写成抒情段落。

## 中文零散草稿重构

识别输入论点、证据、条件和逻辑跳跃，先重建关系再写正文，而非逐句换词。一个段落围绕一个核心观点，根据内容选择因果、比较、递进或限定的自然顺序。

Word 正文使用纯文本、全角标点和必要术语，不强迫“极度正式”或生僻表达；例如口语转书面语应以自然准确为准。论证缺证据时标在正文外，不自造事实连接。

```text
Part 1 [Refined Text]：重构后的中文正文。
Part 2 [Logic Flow]：正文外简要说明论证重组依据与仍缺的材料。
```

## 微缩、微扩与大幅篇幅调整

微缩英文可参考减少 5—15 词：压缩冗余从句、填充词和重复结构，依实际关系调整主动/被动。保留所有核心信息、技术细节与参数，不“先删数据后说没变”。

微扩英文可参考增加 5—15 词：显式说明原文已有的前提、关系或结论边界，增加必要连接，不能添加无依据结果、无信息形容词或同义废话。大幅缩写/扩写按用户目标单独规划，不套微调幅度。

```text
Part 1 [LaTeX/正文]；Part 2 [中文直译（英文本任务）]；Part 3 [Modification Log]。
另核对保留信息与实际长度；篇幅不达目标时说明证据/信息约束。
```

## 终稿逻辑红线审查

终稿快速检查预设文本已多轮修改，只报告阻碍理解的逻辑矛盾、未说明的术语混用和严重语法歧义，不提出可改可不改的风格建议。无实质问题输出 `[检测通过，无实质性问题]`；有问题列具体位置和理由。该模式不能替代完整 [peer-review.md](peer-review.md) 和保真/引用核验。

## 图表文字和实验分析

只处理已有图表的标题、图注、表注和数据分析文字；按 [results.md](results.md) 说明测量、条件、真实比较、趋势、敏感性、效率取舍与消融。图注不能超出数据结论，LaTeX 特殊字符按 [latex.md](latex.md) 处理。

不搬入实验绘图推荐、架构图提示词、生成图片或环境配置模式。上述文字任务无需新增命令。
