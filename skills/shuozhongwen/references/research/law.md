# 法学写作与引注

整合 writing-law 技能及模块增量。共用 [core.md](core.md)，涉及法律事实时核对适用法域、时间、效力与原始来源；不能把样例法条、案号和书目当作已核实材料。

## 研究路径与结构

| 类型 | 推进方式 |
|---|---|
| 问题导向 | 问题 → 现行规范及不足 → 比较/理论分析 → 建议 → 结语 |
| 规范分析 | 概念 → 构成要件 → 法律效果 → 适用争议 → 结论 |
| 案例研究 | 案情事实 → 争议焦点 → 裁判理由 → 学理评析 → 制度反思 |
| 比较法 | 问题 → 本法域规定 → 可比较域外制度 → 比较与借鉴 → 建议 |
| 实证研究 | 明确问题与样本 → 数据/案例库/问卷/访谈 → 分析 → 适用边界 |
| 立法或理论研究 | 基础概念、规范目的和真实实践 → 可论证主张 → 方案与局限 |

引言明确问题意识、意义、方法和范围。正文把法条、司法案例、学说与主张连接，交代推理标准和可能反驳。结论回应论证，建议应有制度依据与适用条件，不能只用“完善法律”概括。

## 规范分析与案例分析

规范分析先确认条文、版本、法域与效力，再按所需解释方法说明文义、体系关系、目的、历史背景与比较材料。每种解释要有实际材料，不为凑“六种方法”添没有根据的背景。

案例分析分别记录事实认定、争议焦点、裁判理由、理论评价和规则建议。区分法院的原有理由与作者分析，不能把意见写成案中事实；精确引用法院、裁判类型、时间和案号。

比较法选择可比较制度，说明标准、维度与社会/制度语境，讨论移植条件与本土适用限制。实证研究报告真实样本来源、筛选和分析过程，不能从便捷样本推断整个法域。

## 法学语体

术语准确、推理严密、语气客观。以具体适用问题替代“不合理”，以可论证的法律解释或规范缺陷替代“法院判错了”“法律有漏洞”。学科需要表明立场时可用“本文认为”“笔者主张”，仍须支撑理由；不能用“应当认定”自动替换不确定事实为确定结论。

文义、体系、目的、历史或比较解释等术语只在实际使用时出现。“基于以上分析”“由此可见”须有真实推理，避免公式化结尾。

## 中国法学引注字段

按照目标期刊的引注规则；《法学引注手册》可作参考，适用版本由目标要求确定。格式模板中的占位符全部来自已核实材料：

```text
著作：作者：《书名》，出版社年份版，第 x 页。
期刊：作者：《文章题名》，载《刊名》年份年第 x 期，第 x 页。
法条：《法律全名》第 x 条第 x 款第 x 项（需要时说明版本/施行时间）。
案例：案件名称，法院名称（年份）案号，裁判类型及定位。
司法解释：《解释名称》（文号）第 x 条。
网络材料：作者/发布机构，题名，网址，发布日期与实际访问日期。
```

首次引用完整，重复引注按目标规则处理：紧接上注可用“同上注，第 x 页”，非紧接可用“作者：前引注[x]，第 x 页”。须核对修改后注号不失效。尽量引用原始材料，确需转引注明“转引自”及实际读过的出处。

## 外文引注

```text
英文著作：Author, Book Title (Publisher Year), p. x.
英文期刊：Author, "Article Title", Journal, Vol. x, No. y (Year), pp. x–y.
德文著作：Autor, Buchtitel, Auflage. Aufl., Verlag Jahr, S. x.
日文著作：著者『書名』（出版社、出版年）x 頁。
```

原文姓名、题名、版本与页码不可自拟。外文法律材料的法域、版本和裁判体系不能当作本法域规则。法条、司法解释和案例核对原始发布或法院材料及有效状态，不只搜索二手转载。

## 投稿与终检

按实际目标核对字数、注释、引文、匿名要求和材料。双盲稿的正文与元数据遵循目标规定。查重或相似性阈值不自设，不把上游“一般低于 15%”作为所有期刊要求。

验收：问题明确、论证层次连续、结论与理由一致；法条版本与引用准确、案例完整、书目与脚注匹配、重引注号正确；术语稳定、无错字/口语；观点出处和原创分析区分；比较法适用条件明确。
