# 学术预审、反馈与返修

整合 peer-review 技能、模块详细审查与审稿提示。保留 shuozhongwen 原有评审打分和按问题改写机制；学术内容审查补充到同一反馈流程，不另设覆盖原评分的总分系统。

## 先把握研究

先用 2—3 句话概括核心问题/假设、方法、实际发现和论文定位。核对科学/学术意义与目标体例，指出真正的重大缺陷。未读材料、不完整方法或不可访问数据要明确审查范围，不能写成确定存在问题。

## 逐节审查

| 部分 | 实际检查 |
|---|---|
| 标题与摘要 | 具体准确，覆盖方法与关键结果，中英文对应，未夸大，读者可理解 |
| 引言 | 动机与目标明确，先前研究覆盖，空白由证据支持，贡献边界可验证 |
| 方法 | 设计适合问题，输入到输出清楚，材料/参数/软件/协议足以复现，真实伦理与数据处理 |
| 结果 | 评价顺序清楚，指标/表图口径正确，效应/区间/p 值恰当，阴性和失败结果不被挑掉 |
| 讨论 | 数据支持与推测分开，文献比较准确，矛盾证据未忽视，局限/外推条件具体 |
| 结论 | 回应研究问题，贡献有对应证据，不引入未论证发现 |

方法重点核对样本量/功效、随机/盲法、纳排、收集协议、计算软件与版本、分析计划和多重比较。结果警惕选择性报告、错误检验、缺变异度、过拟合/循环分析、批次或混杂问题、缺关键对照。讨论警惕从相关作因果、无机制证据的机制声明和过强外推。

## 方法、统计与透明度

依据 [statistics.md](statistics.md) 核对独立性、适用正态/方差假设、参数/非参数选择、缺失处理、效应量、区间、p 值、校正和功效依据。实验核对公平对照、足够重复、混杂控制、随机和盲法是否真实实施。

检查数据/代码/材料实际可用性、存储位置或登录号、共享限制的理由及复现说明；“不公开”与“不存在”不能混淆。按设计核对报告规范。不要求超出范围的新实验或因个人风格偏好判失败。

## 偏倚与逻辑判断

| 类型 | 检查问题 |
|---|---|
| 确认/发表/挑选偏倚 | 是否只写支持发现，缺阴性研究或遗漏计划结果 |
| HARKing | 看过结果形成的假设是否被写成事前计划 |
| 抽样/志愿者/流失/幸存者偏倚 | 选择和退出如何限制样本代表性 |
| 观察者/回忆/社会期望/工具偏倚 | 测量期望、回顾性资料或工具问题是否影响结果 |
| P-hacking/结果切换/亚组挖掘 | 是否多次尝试、切换结局或未校正多重分析 |
| 因果谬误 | 时间先后、相关、反向因果或单一原因解释是否被混同 |
| 泛化谬误 | 小样本、个案、群体到个体的推断是否越界 |
| 统计谬误 | 基础率、随机模式、多重比较或条件概率是否误解 |

问题必须指向可见材料和后果；怀疑某偏倚不等于证明存在。不要为满足“列三到五个致命问题”的示例数量而制造缺陷。

## 证据质量

干预研究可结合设计类型讨论系统综述/Meta、RCT、观察研究、病例系列与专家意见，但设计名称不保证执行质量。观察性研究可能比有缺陷的 RCT 更可靠，其他学科也不套用医学证据等级。

适用 GRADE 类判断时考虑偏倚、不一致、间接性、不精确和发表偏倚，及大效应、剂量反应与混杂方向等因素；不能在未做对应评价时宣称已完成正式 GRADE。

多个独立研究组、环境、方法的结果收敛和机制/实证一致可增强支持；单一组、无重复、矛盾发现或明显发表偏倚限制结论。把证据质量写成具体支持边界，而非笼统“权威”。

## 报告与改写闭环

保留现有评审分项、分数和前后对照。学术预审可使用如下附加报告结构，数字评级只有已有评分或用户明确需要时提供，并注明口径，不与文字质量分或 AI 率混淆：

```markdown
## Review Report
- Summary：研究与实际结论的短概括。
- Strengths：有材料支撑的贡献。
- Major concerns：关键问题及对有效性的影响。
- Minor concerns：清晰度、细节、格式问题。
- Overall recommendation：适用时给接受/小修/大修/拒稿的模拟建议及依据。
- Review scope：实际已读材料、未核实部分。

## Strategic Advice
| 位置 | 问题与证据 | 为什么影响论文 | 具体修改/补充 | 是否本轮可改 | 验收依据 |
|---|---|---|---|---|---|
```

主要意见须清楚陈述问题、解释原因、给具体处理方式并区分是否影响核心结论；次要意见不应掩盖主要问题。将意见分为文字可改、需重组论证、需补资料/结果：前两类在授权范围内直接修订，后一类记录缺口，不伪造补充实验。修改后复核原问题、数据保真、引用支持和相邻章节，不仅重新打分。

严苛模式审查原创性、严谨性、贡献验证和公平对照，省去空洞夸赞，但不预设必须拒稿或强行产出指定数量缺陷。所有批评有位置、例子、依据和可操作建议，关注论文而非作者。

## 不同论文的重点

原创研究看设计、对照、复现和数据驱动结论。综述/Meta 看覆盖、检索式、纳排、偏倚、合成方法和异质性，不能只总结文献。方法论文看现有方法比较、协议/代码与实施细节。会议论文结合页数和主题，检查核心贡献与主要声明支撑。学位论文按学校结构与研究深度，不用顶会评语机械评判。

## 返修响应矩阵

```markdown
| 审稿意见 | 接受/部分接受/不接受 | 回复理由与证据 | 修改文件/段落 | 真实新增分析 | 状态 |
|---|---|---|---|---|---|
```

回复审稿与修改正文分别处理，解释性的回复口吻不能泄漏到正文。未实施的分析在回复中也不能声称完成。修改日志保留版本、日期、范围及未解项。

终检确保总结与建议一致、主要问题被论证、意见与论文范围相称、统计/复现/伦理/表图与写作均已按实际材料检查，语气专业，无人身评论或双盲身份泄漏。
