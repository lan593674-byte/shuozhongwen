# 范例：用户认可的标准稿

用户明确说过“这一版就挺好的了，以后可以按照这个标准来”。写同类文字（根据材料写的说明文、课程论坛帖、介绍类短文）时，先读一遍这篇，照它的做法来。

## 这篇好在哪里

- 文体认对了：题目要的是介绍和对比，所以写成说明文，不硬加立场，不用第一人称。
- 第一句就是主题本身，没有开场白，也不交代资料来源和资料的缺口。
- 只用材料里的事实，数字照材料写（两百到四百人、2000 年四分之一），没有补课外史实，程度词也没有加重。
- 短：不到 600 字。每件事多说一两句，而不是把几十个事实压成清单。
- 判断跟在事实后面（先摆萨米人种地、放驯鹿，再说这套描述放到整个北方森林就不都对）。
- 句子长短拉得开（猎物按季节来。人也跟着搬。），用词口语，同一个东西前后用同一个词。
- 没有引号；难译的专名第一次出现时在括号里附英文。
- 检查结果：结构套路 0 处，AI 相似度 0.18（low），事实核查存疑 0 条。

## 原文

亚北极的普遍描述与詹姆斯湾的克里人

亚北极（Subarctic）的普遍描述说的是北方森林里的打猎采集生活。那里冬天冷，夏天短，生长季太短，土壤又贫，所以很少种庄稼，人靠驯鹿、驼鹿、海狸和鱼过活。猎物按季节来。人也跟着搬。秋天到驯鹿南迁的路上拦截，冬天设陷阱、凿冰捕鱼，夏天聚到河边把鱼切开，晒干或熏干存起来过冬。一个区域群体有两百到四百人，可环境很少允许整个群体长久聚在一处，所以一年里大半时间散成几户人家的小队各自觅食，到夏天捕鱼时才重新聚拢。

北欧的萨米人（Sami）从中世纪晚期起就种地，驯鹿放牧在北欧和俄罗斯远东也很普遍，一路南推到中国北方。所以这套描述放到整个北方森林就不都对，因为它说的主要是加拿大亚北极。

克里人（Cree）住在詹姆斯湾（James Bay）以东和以南，正属于加拿大亚北极，所以他们的传统生活和这套描述对得上。他们秋天猎驯鹿，这时的驯鹿最肥，皮也最好，吃不完的肉晒干捣成粉，拌上油脂做成肉饼（pemmican），存着过冬。他们相信动物和物件里都有灵，管灵叫曼尼图（manitou）。熊尤其受敬重。猎到熊以后，要把熊的头骨挂到树上，让它能望着水面。

到今天，打猎对克里人仍然重要，可南方的工业社会为了找资源，越来越多地占到他们的土地上来。水坝放水淹掉土地，采矿和砍林子占了猎场，贸易壁垒和动物权利运动又让打猎和下套子难以维持。即便这样，2000年还有四分之一的克里人全职打猎。克里人出名，是因为他们努力阻止在自己传统的土地上修水电工程。
