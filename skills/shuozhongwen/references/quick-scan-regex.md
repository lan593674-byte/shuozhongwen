# 文本信号正则与格式检查

本页保留四个历史正则块及其顺序，供 `haohao_scan.py` 和 AI 相似度模型的 `haohao_markers.py` 读取。正则只是发现可复核位置，写作规范以 `research/core.md` 为主。命中数量不等于写作质量，不能用编号、主题句、对比句或文献归属的数量判退，不能为清零而删除研究信息。

## 1. 编号标题

编号是论文、报告和技术文档的正常格式。命中供核对章节层次与用户要求；论文模式直接跳过本项。其他文体也不因使用编号而判退。

```regex
^#{1,6}\s*([一二三四五六七八九十]+[、\.]|第[一二三四五六七八九十0-9]+[章节、]|[0-9]+[\.、）)]|其[一二三四五六七八九十]|第[一二三四五六七八九十0-9]+[步刀条个板斧维度方面]|[一二三四五六七八九十0-9]+[刀步条板斧维度][^\n]*)
```

## 2. 对比表达

检查对比是否准确、是否重复空泛。真实对比、讨论他人的观点以及必要限定可以保留；不设置全文允许几处的硬阈值。

```regex
(不是[^，。；\n]{1,30}[，,](而)?是[^，。\n]{1,30}|这不是[^，。\n]{1,30}|管的是[^，。\n]{1,20}不管|不在[^，。\n]{1,15}[，,]?而(在|是)|你以为[^，。\n]{1,30}[，,]?其实|(看似|表面上)[^，。\n]{1,30}[，,]?实则|回头才(发现|明白)|真正[^，。\n]{1,20}的是|不重要[，,]重要的是)
```

## 3. 疑似空泛表达

检查词语后是否有具体研究对象、事实或证据。只有实际空泛时才按原意改写，不以词语出现本身决定质量。“本文”“本研究”“实验结果表明”“表 X 显示”等客观主语符合上游学术写作规范。

```regex
(值得深思|值得关注|值得玩味|不禁让人|引人深思|发人深省|令人深思|不禁要问)
```

## 4. 中文正文半角标点

在可编辑的中文正文中统一标点。代码、命令、URL、数字、英文原文、公式、逐字引语、表格和参考文献按各自格式及数据保真约束保留。脚本保护代码块、行内代码、URL、数学环境、LaTeX 引用/交叉引用/标签/书目命令参数、中文引号和引用或表格行；剩余命中需要核对，不得改动被保护材料。

```regex
[一-鿿][,;:]|[一-鿿],[^0-9]|[一-鿿]\.[^0-9]
```

## 执行与报告

运行 `python S/haohao_scan.py 稿件 --json`，论文加 `--paper`。四项输出均保留 `count`、`hits` 和 `passed`；`gate` 区分格式检查与内容提示。前三项只提示，不按数量阻断；半角标点在未被保护的中文正文中作为格式检查。`polish_check.py` 同时报告不可见字符和 AI 相似度，`structure_scan.py` 的结构信号也只作提示，语言质量由独立六项评审决定。

在修改报告中记录实际执行结果、真实问题的处理方式及有依据的保留理由。AI 相似度是既有校准模型的统计信号，不是第三方检测器的 AI 率，不保证通过任何平台。短文或缺少校准数据时如实写未能评分，不当作低 AI 率。复审最多三轮，不为降低统计分数反复破坏语言和研究信息。
