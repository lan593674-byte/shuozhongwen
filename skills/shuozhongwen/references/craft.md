# 文学任务的补充表达

仅在用户要求散文、随笔、小说等文学表达时读取。自然行文和信息保留以 `research/core.md` 为准；本页不要求说明文、评论或论文补文采、发现、画面或作者态度。

先读原稿主线、视角和真实素材。动作、实物、声音等可呈现经验，但只用用户材料或获准核实事实。缺经历、引语、感官细节时列给作者，不编亲历。

调准确动词、自然语序、详略和句长，保留有意义解释、承接和重复。比喻、回扣、主题句、单句段和小结按语境决定，不按固定次数禁用，不强求出现。已完整自然就轻改。

开头结尾服务内容与要求，不套开场白或空泛升华，也不一律禁止总结。删空话不必强补新事实，保留有效信息即可。读出声检查语气节奏，保真和独立评审沿主流程，不为统计分数改变作者意思。
